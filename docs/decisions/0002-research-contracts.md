# ADR 0002 — Research contracts

Date: 2026-10-19
Decision: PROPOSED
Implementation: Initial contracts only

## Purpose

Represent source identity, conservative PIT availability,
canonical evidence spans, financial observations,
traceable claims, and independent review decisions.

## Provenance

These are newly authored native implementations,
informed by the read-only audits of legacy
Retrieval Lab and Financial Research Workflow.

No legacy implementation files were copied.
No runtime imports or shared data paths exist.

Any future selective code migration must record
source repository, commit, file SHA, permissions,
changes, and verification.

## Evidence limitations

Document metadata and claimed SHA values are contracts.
They do not prove that the original PDF exists,
is licensed for use, or matches those hashes.

Canonical spans must later be checked against
actual verified canonical source text.

Synthetic unit tests do not qualify a real document.

## Financial limitations

Comparability metadata provides a rejection screen,
not a financial-semantic truth oracle.

Matching fields do not authorize a claim.
Implicit comparisons and category-to-number binding
errors still require independent semantic review.

No publication API or ADMIT authority is created here.

## PIT rule

For date-only publication evidence, availability
begins at 00:00 Asia/Shanghai on the next
calendar day. This is a conservative research
admissibility boundary, not a trading rule.
